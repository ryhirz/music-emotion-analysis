# 面试小本本 · 音乐情感分析工具

> 用途：记录本项目可讲的技术亮点与「面试防御话术」，随时背诵。
> 维护建议：每个亮点都准备「一句话结论 + 技术细节 + 为什么这么做」。

## 项目一句话简介（30 秒电梯演讲）
基于 **GTZAN** 曲风数据集，用 **librosa** 提取 37 维音频特征，训练**随机森林**完成「音乐情感分析」：用户上传一段 mp3/wav，系统返回情感标签（活力 / 激昂 / 平静 / 欢快 / 忧郁 / 律动）与置信度。
**技术关键词**：传统机器学习（非深度学习）、纯 CPU 可跑、特征可解释、scikit-learn 全家桶、Gradio 零前端部署。

---

## 亮点 A：频谱对比度（Spectral Contrast）是王者

**一句话结论**：区分情感最核心的特征不是节奏 BPM，而是频谱对比度。

**背诵话术**：
> "在做特征重要性分析时，我发现区分情感最核心的特征不是大家常以为的节奏（BPM），而是频谱对比度（Spectral Contrast）。因为它能很好地刻画音色的'攻击性'和'粗糙度'，比如 Metal 的失真吉他对比度极高，而 Classical 的原声乐器对比度平缓。这让模型能精准区分'激昂'和'平静'。"

**技术支撑**：ANOVA F 值 Top5 = `contrast_4, contrast_5, mfcc_1, contrast_3, spectral_rolloff`；随机森林重要性 Top5 = `contrast_4, contrast_5, rms, mfcc_4, mfcc_1`。频谱对比度占据前两席。

---

## 亮点 B：BPM 的反直觉表现

**一句话结论**：BPM 没进重要性 Top 10，因为各曲风节奏重叠。

**背诵话术**：
> "一个有趣的发现是，BPM（节拍速度）并没有进入特征重要性 Top 10。我分析原因是，GTZAN 数据集中大部分现代流行曲风（如 Pop, Disco, Rock）的 BPM 都集中在 110–130 之间，导致速度特征产生了'重叠'。真正拉开情感差距的是音色和能量，而不是单纯的速度。这也证明了多维特征组合的必要性。"

**技术支撑**：6 类情感 tempo 均值 110–126 BPM，区间高度重叠；而 spectral_centroid / contrast / rms 在不同情感间区分明显。

## 阶段 1–5 结果体检话术（训练完成后填写）

> 以下模板用于面试被追问"为什么准确率不高 / 为什么分错"时防御。

**预期区间**：6 分类、标签是曲风硬映射来的，Macro-F1 在 **60% ~ 75%** 都正常。
**心态**：不追求 95%+；过高反而说明模型"记住了曲风而不是情感"，易被 challenge。60–70% 真实准确率 + 合理解释，是最健康的简历项目状态。

**合理的混淆（加分项）**：
- 活力(Disco/Reggae) ↔ 律动(HipHop)，或 激昂(Rock/Metal) ↔ 活力：都高能量强节奏，人类也会分歧，符合音乐直觉。
**不合理的混淆（需警惕）**：
- 平静(Classical) ↔ 激昂(Metal)：说明过拟合异常噪声或数据划分问题。

**少数类（欢快=Pop, 100 首）召回率偏低时主动说**：
- "后续可用 SMOTE 过采样或 class_weight 加权优化少数类。"

### 实际结果速记（2026-09-01 实测，供你做结果体检）

- **数据**：999 条、37 特征、6 类；train_test_split(8:2, stratify, random_state=42)。
- **三模型 Macro-F1**：随机森林 **0.707** / SVM **0.721** / KNN **0.651**。
- **最优模型 = SVM**（F1=0.721，Accuracy=0.710），5 折交叉验证 **0.721 ± 0.022**（稳定，无过拟合迹象）。
- **各类表现（最优 SVM）**：平静最稳（F1=0.835，声学独特）；律动召回最低（R=0.600，仅 20 首且常误判为活力/忧郁）。
- **主要混淆（合理）**：活力 ↔ 律动、激昂 ↔ 活力——都是高能量强节奏类，符合音乐直觉。
- **结论**：落在 60–75% 健康区间，不是"模型差"，而是曲风硬映射情感的天花板；平静类高区分度再次印证亮点 A（音色对比度才是关键）。

## 常见追问与应对（备用）
- **Q：为什么不用深度学习？** A：数据只有 ~1000 首，深度学习易过拟合；传统特征 + 树模型可解释、CPU 可训、适合作为简历里"从特征到模型全链路打通"的证明。
- **Q：情感标签哪来的？** A：GTZAN 无情感标注，我们按声学特征把 10 曲风硬映射成 6 情感（弱监督代理标签），这一点在 README 已诚实说明。
- **Q：怎么部署？** A：Gradio 做界面 + Hugging Face Spaces 免费 CPU 部署，开箱即用。
